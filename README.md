# Sinlabs (Frontend)

Frontend estático desenvolvido em React 19 com Vite, preparado para integração com uma API.  
Este projeto foi construído para a UNESP, sem dependência de backend no momento, apenas focando na escalabilidade.

A proposta é entregar uma experiência de navegação fluida e bem estruturada agora, deixando o projeto pronto para consumir dados reais assim que a API estiver disponível.

O site está hospedado em:  
https://sinlabs.vercel.app/

## Tecnologias

- React 19  
- Vite  
- JavaScript  
- ESLint
